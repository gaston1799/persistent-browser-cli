# PBC Support

PBC (Persistent Browser CLI) support is provided through the project's public
GitHub repository.

## Get help

Before opening a report, run:

```powershell
pbc doctor
pbc --help
```

Then search the existing issues. If the problem has not been reported, open a
new issue at:

https://github.com/gaston1799/persistent-browser-cli/issues

Include the PBC version, Windows version, the command that failed, and the
non-sensitive error output. Do not include passwords, cookies, authentication
tokens, browser-profile files, government IDs, or other private information.

PBC is community-supported software. Response times are not guaranteed.
